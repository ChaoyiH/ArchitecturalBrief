# 测试科技馆 建筑设计任务书

## 1. 项目概况

占地面积 10000 平方米，位于城市核心区，定位为区域性科普教育基地


## 2. 设计理念 (Design Concept)

### Analysis

本项目位于城市核心区，占地10000平方米，定位为区域性科普教育基地。城市高密度环境要求建筑在有限空间内高效整合功能，增强公共可达性，同时兼顾地标性和可持续性。10000平方米规模需平衡科普展教空间与辅助设施，避免拥挤。案例中，科技馆通过几何标志性、开放性和现代化表达科普本质，故应聚焦空间高效利用、环境融合和创新象征性。

### Directions

**Title**: 地标融合

##### Concept Description

借鉴北京科学中心的几何造型和浙江省科技馆的标志性球体策略，创造象征性建筑形象，强化城市地标属性。核心在于将科技馆的几何美感转化为城市地标，同时整合科普教育功能，确保建筑在核心区环境中具识别性和象征意义，吸引公众参与。

##### Spatial Strategy

建筑形态采用简洁几何体量（如球体或立方体组合）作为核心标识，体量高度不超过30米以符合核心区高度限制。空间组织以中心为互动展区，周围配置展教区，通过垂直流线连接，形成紧凑而开放的核心空间。外立面使用现代材质（如金属和玻璃）打造科技质感，确保形态在周边环境中具独特性。

**Inspiration Source**: 参考北京科学中心的几何造型策略和浙江省科技馆的标志性球体元素


**Title**: 开放教育

**Concept Description**: 受北京科学中心的展教结合理念启发，强调功能重组与社区融入，打造开放式科普教育空间。核心内涵为将展教功能与城市空间无缝连接，形成流动的教育环境，促进科普教育的社会化与日常化，契合核心区的高人流需求。

##### Spatial Strategy

建筑布局以灵活空间模块为主，底层设计开放式公共大厅（如展教区或广场），与城市街区无缝衔接，避免封闭感。内部空间采用线性布局或院落式组织，确保自然通风采光，并通过共享空间（如中庭或平台）增强互动。外立面使用透明元素，营造开放性和透明度，符合核心区活力属性。

**Inspiration Source**: 参考北京科学中心的展教结合策略和开放空间融合方式


**Title**: 科技象征

##### Concept Description

借鉴宁波科学探索中心的科技感表达和浙江省科技馆的沉浸体验，融入现代科技象征元素。核心内涵为通过数字化材质和空间创新，彰显前沿科技精神，提供沉浸式科普体验，增强对公众的教育吸引力和科学启发性，适合城市核心区的创新氛围。

##### Spatial Strategy

建筑形态采用流线型或多面几何体，体现动态科技感，高度控制在25-35米以与周边协调。空间组织设计三层：底层为常规展教，中层为互动沉浸区（如球形影院或VR空间），顶层为教育实验室。外立面使用高性能材料（如ETFE膜或智能玻璃）形成科技光感，内部空间利用智能化和数字化元素（如传感器引导流线）提升体验，确保象征性与功能性并重。

**Inspiration Source**: 参考宁波科学探索中心的现代科技感表达和浙江省科技馆的沉浸式空间策略





## 3. 核心枢纽 (Central Hub)

### Spatial Concept

**Theme Name**: 时空之门（中庭）

#### Form Description

24米通高的中庭空间，采用双曲面钢结构网架配合ETFE气枕天窗形成“天空之眼”。中庭沿长轴设置一条连续的弧形环廊，串联各层展厅。底层周边以低矮透空的展墙与可移动展台，界定“集散场”；二层及以上以玻璃扶手与挑空栏板建立通透视线；中央留出直径18—20米装置区，避免主体交通流线穿越，确保参观秩序。

**Atmosphere**: 明亮、开放而具有科技仪式感：天光由ETFE天窗均匀漫射，结合智能遮阳与LED光带随运行节律缓变；近人尺度采用温暖木饰面与金属细部，提升可亲近性与精细度。整体氛围兼具庄严、凝聚与探索的科技感。


### Scale Reference

**Height Suggestion**: 建议通高约24米（贯通1—4层），并通过局部挑高至30米形成视觉缓冲区。

**Area Suggestion**: 核心中庭（含环廊内侧可展地）约1,200—1,600平方米；安全疏散净距与设备检修通道另计。

#### Rationale

参考江西省、青海省、湖南省、绵阳市等科技馆综合大厅经验，高度24米通高可形成兼具仪式与视线的“共享大厅”，便于人流集散与活动举办；面积设置1,200—1,600平方米契合万级规模科技馆的中庭比例关系，在不牺牲垂直交通与安全疏散的前提下，提供足够的展陈弹性。


### Circulation Hub

#### Vertical Transport

采用“一中两梯”布置：中央一组双向6米跨飞天梯（玻璃观光电梯）作为主客流枢纽，承担密集上访与应急通行；两侧各设一组6米跨自动扶梯，提供连续上/下行引导；底层东侧增设两部疏散楼梯与一间无障碍电梯，构成冗余与合规通道。扶梯与电梯均可视化排布于环廊内侧，配合导视灯带形成明确的“上行带”。

#### Visual Connection

环廊采用挑空玻璃栏板与通长LED灯带统一视线导向；装置区设直径18—20米透明玻璃地台，形成向心视域；上层展陈面向中庭设置半开放门洞与可开关展示面，保持层间可视穿透。装置与扶梯之间预留不小于8米的通视距离，避免人流遮挡焦点。


### Feature Element

**Type**: 智能交互环——悬挂互动艺术装置（兼具科普展项功能）

#### Description

位于中庭上空的直径18—20米环形结构：由内圈LED阵列、外圈不锈钢骨架与可编程纱网构成，依托屋面钢索与可调吊点悬吊。装置以“时空之门”为主题，融合馆藏科学元素与城市象征，通过动态光线、缓变速度与分层影像讲述科学演进与社会发展。观众通过底层互动台与移动端控制环体旋转与光影变化，形成可视化互动数据；侧壁嵌入2.0×12米信息交互屏，补充装置说明与科普内容。环体下方设直径16米玻璃地面平台，满足承载并保持视线通透。




## 4. 展陈体系 (Exhibition)

### Spatial Parameters

#### Ceiling Height

建议主要展厅净高范围：首层展厅净高8.0米，标准层展厅净高6.0米。依据《博物馆建筑设计规范》条文4.2.3对展厅净高的基本要求（科技馆对层高要求通常高于一般博物馆以容纳大型互动展项）和江西省科学技术馆案例中中央大厅及常设展厅的高净高设计（如巨型机甲展项所需）。

**Column Grid**: 建议柱网尺寸：9.0米×9.0米。依据内蒙古科学技术馆案例中大跨度双曲面空间管桁架结构（营造开阔空间以适应航天模型等大型展项布置）和《科学技术馆建设标准》对展厅空间适应性要求。

#### Floor Load

建议楼面荷载值：一般展厅区域3.5 kN/m²，重型展品区（如航天或机械展项区）5.0 kN/m²。依据《科学技术馆建设标准》对科技馆展品荷载的特殊要求（科普展品通常较重，如内蒙古馆航天模型展项）和江西省科学技术馆案例中互动展项的部署。


### Layout Strategy

#### Organization Type

推荐空间组合形式：大厅式结合串联式。大厅式中央序厅作为核心，展厅环绕布置，辅以串联式走廊连接。理由是江西省科学技术馆案例中中央大厅与展厅组合形式（序厅宽敞明亮，标识展项突出，串联流线组织有序），以及内蒙古科学技术馆案例中大跨度公共空间与主题展厅衔接（易于控制人流和强化科普教育体验）。

#### Circulation Flow

观众参观流线建议：基础自由选择流线，配合单向强制流线于高峰期。自由流线允许观众自主探索互动展项（如儿童科技乐园和基础科学展区的动手体验）；高峰期时采用单向强制流线，从序厅入口引导至展厅，出口独立。理由是江西省科学技术馆案例中自由参观模式与内蒙古科学技术馆案例中高峰期人流控制（如单向流线避免拥堵），符合科技馆互动性和安全性要求。


### Functional Zoning

**Zone Name**: 儿童科技乐园

**Floor Suggestion**: 首层

**Area Concept**: 设计概念：以低龄儿童为核心，提供寓教于乐的互动体验，如水世界、小球乐园等展项。空间特征：净高6.0米，柱网9.0米×9.0米，以柔性材料和安全防护设计，营造开放、可移动的游乐环境。

**Reference**: 参考了江西省科学技术馆中儿童科学乐园的设置（位于一楼，针对低龄儿童设计，互动展项丰富）。


**Zone Name**: 探索与发现

**Floor Suggestion**: 标准层（如二层）

**Area Concept**: 设计概念：展示基础科学原理，如声、光、电、磁等经典物理现象，鼓励观众动手探索。空间特征：净高6.0米，柱网9.0米×9.0米，配备可移动展项平台和模块化展柜，适应灵活布展需求。

**Reference**: 参考了江西省科学技术馆中探索与发现展厅和内蒙古科学技术馆中探索与发现展区的设置（展示基础科学互动体验）。


**Zone Name**: 科技与生活

**Floor Suggestion**: 标准层（如三层）

**Area Concept**: 设计概念：聚焦科技在日常生活中的应用，涵盖生命健康、交通能源等领域。空间特征：净高6.0米，柱网9.0米×9.0米，楼面荷载提升至5.0 kN/m²以容纳重型展品（如生命健康展区的人体模型）。

**Reference**: 参考了江西省科学技术馆中科技与生活展厅的设置（关注科技应用和生活场景）。



### Environment Requirements

光环境要求：主要展厅采用人工光控制，照度调节（一般展区200-300 lux，互动展区300-500 lux），避免眩光和褪色；可调光系统支持展项变化（如VR体验区需低照度）。依据《博物馆建筑设计规范》光环境标准与案例中科技馆光控制实践（如江西省馆人工光主导）。声学环境要求：一般展厅背景噪声控制在40 dB(A)以下，采用吸声材料和隔音设计；互动展区允许适度噪声，但需独立声学分区以防干扰（如儿童区和机械展区）。依据科技馆声学控制标准和内蒙古科学技术馆案例中互动展项噪音管理经验。

## 6. 科教研学 (Science Education)

**Education Concept**: 从'参观'走向'探究'，以动手实践和科学表演为核心，构建馆校深度融合的沉浸式科普教育生态，提升公众科学素养。

### Signature Activities

**Name**: 液氮科学实验秀

**Format**: 现场演示结合互动

**Spatial Requirement**: 需中庭或大型开放空间（如100平方米），配备通风系统和防溅围栏的演示台，确保安全操作。


**Name**: 科普大讲坛

**Format**: 专家讲座配合互动问答

**Spatial Requirement**: 需阶梯教室（80平方米）或多功能厅，可容纳100人，配有投影设备和移动讲台。


**Name**: 科技馆奇妙夜

**Format**: 夜间体验和过夜活动

**Spatial Requirement**: 需专用教育区（如200平方米），配备过夜设施和安全监控系统，保证独立通风和供电。


**Name**: 机器人编程实验室

**Format**: 小组工作坊协作实践

**Spatial Requirement**: 需工作室（50平方米），配备编程设备和机器人套件，配有移动实验台和电源插座。


**Name**: 3D打印创意工坊

**Format**: 动手实践工作坊

**Spatial Requirement**: 需开放式展厅工作站（30平方米），配备3D打印机和操作台，观众可参与部分步骤。



### Spatial Integration

#### Embedded Labs

在展厅核心展区设置3-4个‘玻璃盒子’实验室（如3米×4米单元），采用透明围护结构，配备可开启通风口和多功能实验台，实现展览与实验空间的无缝融合。操作区观众可从外部观察关键步骤，部分装置如化学反应或机器人编程可开放互动窗口，允许实时参与，减少传统隔墙隔离。


### Public Performance

#### Public Performance

利用主门厅中庭（面积200平方米）和大台阶设计环形观众席（约150座），设可升降演示平台（直径3米）配备投影幕布和机动音响系统，用于科学秀表演。通过活动隔断和可收纳座椅，灵活转换为讲座或工作坊空间，保证与展厅流线的视觉连通性。


### Dedicated Education Zone

#### Room Configuration

建议配置独立房间：2间通用科普教室（每间80平方米，配备可移动桌椅和智能黑板），1间物理实验室（120平方米，配牛顿环等演示设备和实验台），1间化学实验室（100平方米，配备排风系统和安全防护设施），1间生物实验室（80平方米，配备生物安全柜和显微设备），1间机器人编程工作室（60平方米，配机器人套件和电脑工作站）。总面积约700平方米。


**Zoning Strategy**: 教育区建议位于首层东侧或后侧，通过专用安全通道连接展厅，减少与公共流线交叉。设独立入口（3米宽）和垂直交通（货运电梯和楼梯），支持夜间或周末独立运营。垂直上与其他区域保持缓冲区，避免声学干扰。



## 7. 公共服务 (Public Service)

### Entrance Lobby

#### Flow Strategy

采用单向渐进式流线组织，设置4道功能分区：售票服务区（门厅北侧）→安检缓冲区（16米进深）→智能存包区（6×4米模块化布置）→检票分流区（8个检票通道）。各分区之间保持3.5米过渡间距，形成S型动线引导，避免人流对冲。高峰期启用西侧辅助入口进行压力分流。

#### Spatial Requirements

综合大厅净高不低于12米，面积控制在1500-1800平方米，确保1.5平方米/人的人均占有空间。序厅顶部采用渐变LED光带配合可调光天窗，营造科技感光影效果。地面选用防滑耐磨花岗岩，设置直径0.8米的导向性圆形地贴，引导观众向展厅分流。

#### Key Facilities
