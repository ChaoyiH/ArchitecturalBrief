## 4. 特效影厅体系规划 (Special Theaters Planning)

### 4.1 行业主流影厅类型分析
科技馆主流配置为巨幕（IMAX）、球幕及4D动感影院，部分场馆创新引入LED全沉浸式、碗幕等新型设施以强化科普互动体验。
- **巨幕影院 (IMAX)**：采用超大画幅与高分辨率激光放映系统，提供广阔视野的观影体验。；Evidence：巨幕影院（IMAX GT激光影厅）：银幕宽29米、高21米...采用世界先进的IMAX GT激光4K放映系统
- **球幕影院**：利用半球形或360度银幕包裹观众视野，常用于天文或沉浸式科普展示。；Evidence：拥有半球形银幕，提供沉浸式观影体验，常用于播放天文、海洋等科普影片
- **4D动感影院**：结合立体视觉与震动、风雨等环境特效，提供多感官刺激。；Evidence：结合3D立体画面与环境特效（如震动、吹风、喷水等），提供多感官的动感观影体验
- **沉浸式/异形影院**：包括LED全沉浸、碗幕等特殊形态，用于特定主题展示。；Evidence：LED全沉浸式影院; 沉浸式碗幕影院

### 4.2 建设趋势洞察
- **基础特效与传统球幕的标配化** (<2015): 早期科技馆建设多以“4D影院+传统球幕”为核心配置。侧重于通过震动、风雨等物理特效提供基础感官刺激，或利用球幕的大视场角提供包裹感，但投影分辨率（多为灯泡机）与沉浸深度相对有限。 | Evidence: 福建省科学技术馆（老馆4D影院，<2015）；湖南省科学技术馆（传统球幕+4D，<2015）
- **超高清激光与多元沉浸形态** (>=2015): 新建场馆全面拥抱激光投影技术，追求8K超高分辨率与极致亮度。引入IMAX GT、LED全沉浸式影院等前沿形态，突破传统银幕限制，打造世界级、高沉浸感的视觉奇观，强调极致视听体验。 | Evidence: 山东省科学技术馆（IMAX GT激光/8K球幕/LED影院，2022）
- **影展融合与异形交互体验** (>=2015): 影院形态不再局限于封闭厅堂，而是向“展厅即影院”演变。出现碗幕、VR动感平台等异形显示，将观影体验与科普展览叙事深度融合，强调交互性与场景化，提升观众在展厅内的停留与互动。 | Evidence: 青岛科技馆（沉浸式碗幕/VR动感平台，2023）

## 10. 重点空间 / 综合大厅与中庭 (Central Hub & Atrium)

### Morphology Panorama

#### Summary

本次分析的科技馆案例展示了中庭从单一交通核向“叙事性空间容器”的演变。剖面设计多采用巨型几何实体（如球体、漏斗）占据核心、悬浮体块咬合或螺旋动线贯穿的策略，强调垂直维度的视觉张力与功能复合，将中庭转化为集展示、观演与交通于一体的沉浸式科幻场景。

#### Archetypes

**Name**: Object-Centric Vertical Void (核心实体型)

**Spatial Diagram Desc**: 在通高共享空间的几何中心置入巨大的实体体量（如球体、漏斗），形成“虚中实”的剖面关系，实体内部通常容纳影院或特殊展项。

###### Typical Features

- 巨型几何体占据视觉焦点
- 功能复合（腹部藏影院/屏幕）
- 强调天圆地方或宇宙意象

**Representative Case**: 湖北省科学技术馆


**Name**: Interlocking Floating Void (悬浮咬合型)

**Spatial Diagram Desc**: 通过扭转、悬浮的盒体空间插入中庭虚空，打破垂直方向的单一性，形成错落的层间关系和动态的剖面轮廓。

###### Typical Features

- 体块嵌入与悬浮感
- 流线非线性
- 虚实空间交错

**Representative Case**: 山东省科学技术馆


**Name**: Circulation-Driven Helix Void (螺旋动线型)

**Spatial Diagram Desc**: 以连续的螺旋坡道作为剖面核心，结合顶部采光，将交通动线转化为核心视觉景观，引导视线与人流向上延伸。

###### Typical Features

- DNA双螺旋结构
- 交通与景观一体化
- 顶部自然采光

**Representative Case**: 海南省科学技术馆


**Name**: Linear Pan-Space (线性泛空间型)

**Spatial Diagram Desc**: 侧重于水平方向的延展，形成宽敞的线性或大跨度“泛空间”，作为连接各功能区块的枢纽及大型活动场所。

###### Typical Features

- 水平向开阔尺度
- 多功能活动适应性
- 功能区块的有机穿插

**Representative Case**: 辽宁省科学技术馆
