## 4. 核心枢纽 (Central Hub)

### Spatial Concept

**Theme Name**: 黄河•时空之环

#### Form Description

首层至四层通高中庭，平面呈“流动环”形态，中央为22米直径的采光孔，环廊由流线型穿孔铝板围合，曲面墙体渐变开窗，顶部设置可调光天幕；环形廊道自然引导观众顺时针流动，形成仪式性的“溯源—入馆—展陈”的空间序列。

**Atmosphere**: 大气明亮、科技感与仪式感并重，光线随昼夜变化，呈现黄河般温和而充满动势的空间氛围。


### Scale Reference

**Height Suggestion**: 建议通高高度18–24米，覆盖1–3层；如展陈需求强烈可延伸至4层形成24米通高。

**Area Suggestion**: 建议核心中庭面积1200–1800平方米；环形步道（宽6–9米）总长度约150–220米。

#### Rationale

参考山东省科学技术馆与青岛科技馆等国内同类项目，综合大厅通常采用多层通高与中庭组织，24米级别可容纳主要展演与视线通廊；依据公共建筑中庭规范与防火分区要求，1200–1800平方米可满足高峰人流的组织与回转。


### Circulation Hub

#### Vertical Transport

在中庭两端布置交叉扶梯组（两台上行、一台下行），每组跨距约10–12米；在北侧增设一处飞天梯（带观光舱体，载重约1000千克，速约0.6米/秒），承担主要人群上行输送；南侧设无障碍电梯（群组两台），与环形步道无缝对接。

**Visual Connection**: 环廊采用45°–60°开口，将地面“黄河—天幕”与二、三层展厅入口形成连续视线廊道；环廊与展厅之间以“退台式”露台过渡，弱化边界，确保1–3层间的相互可视与导引。


### Feature Element

**Type**: 悬挂式动态多媒体装置

#### Description

装置名为“黄河天幕—源与汇”，由悬索吊挂的环形LED阵列与可变光丝网构成，模拟黄河自高原奔流、汇入渤海的叙事弧线。顶部设有可调光天幕与定向扩声，系统可在夜间以水波投射映射黄河形态，配合水雾与光带，营造沉浸式科普场景。装置材质以不锈钢+氟碳涂层与低辐射玻璃为主，表面抗污易维护。




## 5. 展陈体系 (Exhibition)

### Spatial Parameters

#### Ceiling Height

建议首层主要展厅净高≥6.5 m，标准层主要展厅净高≥5.5 m，局部演示中庭或可变形演示区净高≥8.0 m。该参数参考GB 50096《住宅设计标准》与国内外科技馆工程实践（如河南省科学技术馆中庭净高约42 m，山东科学技术馆中央大厅采用通高空间与悬浮体量共同组织竖向空间），满足声光电集成、大尺度交互装置及吊装巡游展需求。

#### Column Grid

建议采用8.4 m×8.4 m或9.0 m×9.0 m标准柱网，必要时在中庭或主秀场采用局部无柱扩展至24 m×24 m。该尺度用于兼容重型航天模型（≥8 t）、1:1潜水器/高铁车头、球幕影院等大型展项及设备检修通道，与湖南省科学技术馆“制造天地”“太空探索”等展厅布置经验相符。

#### Floor Load

建议一般展陈楼面活荷载标准值≥5.0 kN/m²，重型展品区（航天交通、动物生态标本、球幕影院设备）≥8.0 kN/m²，底层局部可结合梁板加固至≥10.0 kN/m²。参考《建筑结构荷载规范》GB 50009-2012（2012年版）关于公众聚集场所活荷载取值，以及山东省科学技术馆、河南省科学技术馆对中庭与大型设备区的承载加强做法。


### Layout Strategy

#### Organization Type

推荐采用“黄河主题中庭+放射式分区”的复合组织：以黄河走向的曲线中庭串联南北向主轴，将“水源—文明—科技—未来”四大叙事轴线布置于环中庭的四个翼楼（2F/3F），首层设置入口序厅与临展，中央大厅承担展间过渡与视觉锚点。该形态借鉴山东科学技术馆的“∞符号”通高中庭与功能互联、湖南省科学技术馆共享大厅的序厅功能、泉州市科技馆一楼序厅动态装置的主题化表达，在黄河文化语境下兼顾通达性与叙事连续性。

#### Circulation Flow

建议采用“单向强制主线+自由支线”的混合流线。入口—序厅—中央大厅形成单向强制主线（含高峰分段放行与临时拥堵缓冲区），展区间以横向回廊和垂直交通连接形成自由支线；高峰期在序厅与中庭周边布置排队区与蛇形队列，通过导览系统对向客流进行时间分割；消防疏散遵循双向疏散及相邻分区互为备用，按GB 50016执行，保证中庭烟控与喷淋覆盖。


### Functional Zoning

**Zone Name**: 黄河与生态文明展厅

**Floor Suggestion**: 首层北翼

##### Area Concept

以“黄河之源—九曲奔流—入海新篇”为叙事主轴，设置沉浸式流域地形模型、动态水位与泥沙模拟、航运与水利工程互动区（水闸、堤防、生态修复），强调人与自然的共生。空间采用大净高与低眩光人工照明结合自然采光，控制声压级于60 dB(A)以下，满足大型沙盘与互动水工模型的安全运行与检修需求。

**Reference**: 参考河南省科学技术馆中庭—主题展项叠加的视觉焦点策略与山东省科学技术馆中央大厅“∞符号”悬浮方盒空间的空间组织手法。


**Zone Name**: 基础科学互动城（声、光、电、磁、力）

**Floor Suggestion**: 标准层东翼

##### Area Concept

采用“多节点、小主题”布展模式，围绕54个科学事件节点设置交互实验岛与演示中岛（如电磁大舞台、光学迷宫、力学塔），提供“体验—探究—反馈”的学习路径，兼容3–8岁儿童与公众群体。空间净高≥5.5 m，楼面荷载≥5.0 kN/m²，必要时在中岛下方增设加固垫层以承载≥6 kN/m²的集中设备。

**Reference**: 山东省科学技术馆“多节点、小主题”的策展经验与湖南省科学技术馆A馆二层的“数理启迪”“能源世界”互动展区配置。


**Zone Name**: 航天与交通科技展厅

**Floor Suggestion**: 标准层西翼

##### Area Concept

以“从黄河到太空”为线索，布置1:1航天器/高铁车头模型、火箭发射演示、空间站体验舱与交通天地交互区，配套吊装口与检修通道，楼面荷载≥8.0 kN/m²并预留局部承重加固。顶部设置设备吊点与检修平台，照明采用高显色指数无频闪LED，眩光控制至UGR<19，满足精密展品保护。

**Reference**: 河南省科学技术馆“太空探索”“交通天地”展厅对重型模型与设备区的承载与检修配置，参考其球幕影院设备的集中荷载与竖向交通组织。



### Environment Requirements

自然光：首层与标准层侧窗设置可调遮阳与低辐射玻璃，控制自然采光在300–500 lx范围，避免展品眩光与褪色；人工光采用分区可调LED，展面维持300–500 lx（文字图像展面500–800 lx），CRI≥90，色温3000–5000 K可调。声学：展陈空间混响时间RT60控制≤1.0 s（首层≤1.2 s），墙面与顶面吸声系数≥0.6，中庭配置定向扩声系统，确保背景噪声≤NC-35。空调与通风：展陈区新风量≥25 m³/h·人，换气次数≥6 ACH/小时；球幕影院与沉浸式演示区采用独立空调与降噪隔振措施。消防与安全：中庭设置点式喷淋+早期响应喷淋（ESFR）覆盖，重型展品区增设局部喷淋与气体灭火预留，楼板预留设备检修口与吊点。



## 6. 特效影院 (Special Theater)

### Theater Configuration

**Type**: IMAX球幕天文影院（IMAX Dome Theater）

**Capacity Suggestion**: 320-360座

**Screen Spec**: 球幕直径25米（内径），球心角约210°，银幕有效直径约22米；倾斜安装球心角15°；IMAX/GT制式兼容放映与光学系统

**Feature Description**: 沉浸式星穹与大河文明叙事，适配黄河主题（地理—水文—文明—生态—治河）多主题片单；支撑天文科普、地球科学、地理地貌、工程治河等大场景科普片源；IMAX球幕具备大画幅与高动态范围优势


**Type**: LED全沉浸式影院（LED Immersive Theater）

**Capacity Suggestion**: 200-260座

**Screen Spec**: LED屏总周长约60米×高6米（P2.5或P3.1；亮度≥1000nit；刷新率≥120Hz；支持HDR10），环绕式360°显示；舞台前区可加2.5米×1.4米LED主屏一块

**Feature Description**: 高亮度、高动态对比的全域影像，适配黄河流域主题的沉浸叙事与艺术影片；具备可变亮度/高灰阶，适合白天与夜间两种运营模式的观感一致性


**Type**: 4D动感影院（4D Motion Cinema）

**Capacity Suggestion**: 180-220座

**Screen Spec**: 双机3D+激光投影或双面LED，幕宽14-16米×高7-9米；平台配置低频≥30Hz动感座椅（风、雨、雾、气味、水雾、爆闪等特效）

**Feature Description**: 多感官互动式科普体验，以工程治河、洪涝灾害避险、黄河文明交通/航运等主题片单为主，提升参与度与教学效果



### Spatial Requirements

**Clear Height**: 球幕影院：内净高≥25米（球心至地面），结构内净空≥30米；LED沉浸厅：净高≥5.0米；4D动感厅：净高≥5.0米；机电层/夹层建议预留≥1.2米与≥0.9米分区

#### Structure Span

球幕影院：无柱大空间，覆盖范围直径≥30米，建议采用钢筋混凝土薄壳或钢网壳+双层金属屋面（保温/隔声/隔热复合），恒载≥2.0kN/m²；屋面活荷载≥1.0kN/m²；LED沉浸/4D厅：无柱空间跨度≥20米×15米，采用大跨钢框架或预应力混凝土；楼面荷载≥4.0kN/m²

#### Acoustic Isolation

球幕影院：外墙/屋面≥55dB(Rw)，机房围护≥60dB；机电井与门洞采用声闸/气闸；屋面设隔振带（双道隔振支座/隔振缝）；座椅区背景噪声NC-25；LED沉浸/4D厅：与安静展区之间设置≥150mm双层空心墙+75mm独立龙骨石膏板+中高频吸声层，机房内设低频消声器；地面减振层厚度≥20mm，通道门设置声闸


### Operational Layout

**Access Strategy**: 设置面向街区的一层独立门厅与安检口，单独对外开放；馆内设置VIP/团体通道与检票闸机；夜间运营使用独立安防与疏散系统，人员流线与其他展区物理隔断；入口外场预留排队缓冲区≥80m²并设置导视与候场设施

#### Support Rooms

球幕：放映机房≥120m²（≥3.5m净高），机柜区/通风/冷却/UPS；布幕维护通道；LED沉浸：主控与渲染机房≥60m²，音视频服务器区≥25m²；4D：动感平台机房≥80m²，座椅维护通道≥0.8m；3D眼镜分发回收台设置于各厅入口缓冲区；等候区总面积≥各厅容量的1.5倍乘以0.8m²/人




## 7. 科教研学 (Science Education)

**Education Concept**: 以黄河为线索的探究式科普：从“参观”走向“探究”，让展教融合、社会参与和馆校合作在滨水科技馆中持续发生。

### Signature Activities

**Name**: 黄河·水之舞科学秀

**Format**: 现场演示+互动问答（结合黄河水沙、沉沙与洪峰概念）

**Spatial Requirement**: 中庭（面宽≥18米、净高≥14米、可承载≥4千牛/平方米）、防水地面与地漏、两侧侧灯光与吊点（≥3千牛/点）、可移动阶梯看台区（容纳200人）、后台化妆间≥25平方米、扩声与投影系统。


**Name**: 黄河夜谈（科学之夜过夜活动）

**Format**: 夜间开放+过夜体验+黄河观测

**Spatial Requirement**: 滨水平台与室外天象区、照明照度≤10勒克斯可分区控制、临时宿营区≥150平方米、直达消防疏散通道、值守与安防间距≤30米、可分区独立出入口。


**Name**: 好奇玩家·水上工坊

**Format**: 沉浸式工作坊（沉沙、治水、堤防结构、传感测流）

**Spatial Requirement**: 展厅内开放式工坊（≥60平方米）、可控水循环系统（≤20立方米/小时）、安全围栏与溢流口、排风（≥8次/小时）、展具收纳墙。


**Name**: 黄河科普讲坛

**Format**: 专家讲座+小型展陈联动

**Spatial Requirement**: 多功能讲坛厅（净面积≥200平方米、容纳150席）、可收放看台、前后场分区、弱光投影与扩声系统、资料展架区。


**Name**: 流动科技馆·黄河巡展

**Format**: 车载巡展+校园/社区联动

**Spatial Requirement**: 场地车行通道净宽≥3.5米、侧向回转半径≥12米、停车位≥8个、展具装卸平台≥40平方米、临时供电与网络。



### Spatial Integration

#### Embedded Labs

在水资源与水利工程展区内部署3个“玻璃盒子”实验室：1）“河沙观测实验室”（约60平方米，面宽≥8米），配明暗可调灯、显微镜与小型水槽，围护为6+6夹胶安全玻璃，设观察窗与讲解位，观众可驻足观看但不干扰操作；2）“洪峰模拟演示墙”（约45平方米，厚度≤1.2米），嵌入透明流槽与可控水泵（≤30立方米/小时），与展项联动定时演示，配备溢流与快速排空系统；3）“黄河生态工坊”（约50平方米），展陈桌椅与收纳墙结合可移动教具，便于课程快速布置。嵌入式实验室均通过可移动展板与展项隔断进行视线与噪声分区，讲解时开启拾音系统确保可听性；操作区与观众区地面高差≥0.3米，设置护栏与防滑条。以上嵌入空间采用模块化展具，检修口隐藏在展柜侧板与后场通道中。

#### Public Performance

门厅与中庭形成一体化的表演性教育空间：一层中庭净跨≥18米、净高≥14米，满足可承载≥4千牛/平方米；地面预留地插与弱电端口，墙面与天花预留吊点（≥3千牛/点）与灯轨；两侧设置可移动阶梯看台（200座），可收纳后形成开放空间。大台阶作为“开放教室”，台阶深度≥900毫米、高度≤160毫米，设防滑条与边缘警示条，可在高峰期用于安全缓冲与临时站立观看区。南向落地窗结合黄河景观，形成“科学与环境”叙事剧场；后台设小型操控间与换装区（≥25平方米），并与教育区后场相通便于布撤场。
