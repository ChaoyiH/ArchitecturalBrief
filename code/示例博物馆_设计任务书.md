# 示例博物馆 建筑设计任务书

## 项目概况
本项目为滨水复合型科普场馆，目标是在滨水环境中构建一个集科普教育、城市公共文化、自然与人类文明叙事、科技影像与研学体验于一体的地标性文化设施。项目以“水”为核心叙事与城市接口，通过灰空间和复合一体化策略将展陈、公共活动、研学实验与城市生活高度融合，形成一站式的科学文化目的地。设计以简洁的材质语言与光影装置建立清晰品牌符号，并通过被动气候策略与可再生技术提升全年运营性能。

## 设计愿景
- 水岸方舟：以“方舟”为母题，主体建筑置入滨水前区作为标志性的城市接口，面向水面形成公共舷窗与观景面，前场设置多层滨水步道、观景平台与灰空间，引导观众从水岸进入，再环绕“水心”中庭布置核心展线，确保江景与核心展品的双重焦点。参考武汉科技馆的船型方舟与深圳红立方底部灰空间策略。
- 水织气候廊：以水与风为组织者，通过连续拱廊、通高“船肋”结构与可调遮阳/通风百叶，辅以水面反射降低辐射热，构建亚热带滨水环境的被动舒适带。
- 四馆共城：复合体量承载科普与公共服务，形成共享公共层与屋顶城市平台，承载零售、餐饮、临时展、论坛与儿童科学工坊，书城/艺术角与开放式中庭构成复合活动域，屋顶平台与花园链接滨水慢行系统。参考深圳“三馆一城”与厦门“四馆合一”的群组化协同。
- 光影水钟：以光影装置为“镇馆之塔”，以水为媒介呈现时间的可视化，形成可学习、可参与的公共科普装置与城市精神地标。
- 材料生态：采用耐候、耐湿的低维护材料体系，银灰金属与白色清水混凝土为主，配套被动遮阳、雨水回用与光伏顶棚，提升全年性能与运营经济性。

## 核心空间（The Hub）
本项目的核心空间采用“时空生态峡谷”意象：中庭为线性长廊与通高瀑布式挑空的复合形态，1–5层贯通，净高约28m，顶部设置ETFE气枕天窗与可开合采光带。南北立面采用透明聚碳酸酯板与内发光肌理形成均匀透光的连续面，滨水侧设置可遮雨的彩色金属雨蓬与落水装置，呈现面向水体与天空打开的仪式感。

空间组织与连接：
- 垂直交通：核心区设置双跑螺旋步道式坡道（1/10坡度，3.0m宽，分两段缠绕中庭），两侧各设双向扶梯（1.2m宽）与客梯（各翼楼2部客梯+1部液压无障碍电梯），并设置2条无障碍轮椅升降通道与坡道相衔接。
- 视觉连接：中庭北侧预留透明观景廊，与展厅挑台通过错层开窗与桥廊相接；中庭边缘设置半开放式展陈模块与导视灯带，观众在各层均能“看入峡谷、望向上层”。在关键节点设置“光标”与导览屏幕，显示当层展陈主题与上行路径。
- 标志性装置：中央上方悬挂直径约20m的环形可变形“波光幕”，由柔性薄膜与可控阵列LED组成，形态随风速、光照与观众互动缓慢起伏；下方设置“滨水波纹”互动地坪，感应脚步触发光纹与水雾，寓意为“光与水的共生”，兼具导流与展示功能。

## 功能分区详述

### 陈列展览区
总体组织采用“复合放射式+中庭式核”布局。以中央多功能中庭为连接核，8–10个主题展馆呈放射状/串联状分布，形成“一核多院”。展厅净高参考：首层7.0–9.0m；标准层5.4–6.6m；交互区与设备空间6.6–8.5m；沉浸剧场10–14m。柱网8.1×8.1m或9.0×9.0m为通用区；重载与大型设备区建议9.0×12.0m或12.0×12.0m。楼面活荷载：通用与公众区5.0 kN/m²；儿童互动与跑跳活动区5.0–7.5 kN/m²；大型化石与重载设备区10.0 kN/m²；展项设备机房与临展大活荷载工区15.0 kN/m²。

核心展厅分区与空间要点：
- 滨水生态与河口厅（首层）：以地理分布与生境模拟为核心，展示海洋、河口与湿地生态的迁徙、潮汐与食物网，采用沉浸式水岸景观、声景与嗅味互动，地面耐冲洗防滑；水系展项区域避免直射光，300–500lx人工光；标本区50–150lx。
- 水与文明·时空轴长廊（首层）：时间序列串联水与人类文明（洪水、治水、航运、城建、渔业等），墙面与地面一体化时间轴，关键装置节点（治水模型、水量测算台），净高5.4–6.0m。
- 水循环与流域科学互动厅（2层）：互动型展馆，配备跑台/水工模拟台、雾幕互动与大型互动球体，高荷载与设备层，模块化展台，预留检修与消防系统接口。
- 地球与生命演化厅（2层）：系统分类展示，穿插时间轴，展示矿物、化石、古生物到现代生物群；化石区楼面活荷载≥10.0 kN/m²，采用可拆卸展基座与防震支座；标本/化石区采用高显指LED轨道灯，低UV。
- 儿童水世界（科普乐园）（首层）：3–10岁沉浸游玩与自然体验区，微湿地、沙水渠、互动水循环模型，防滑耐清洗，圆角家具与软包，优先考虑儿童尺度可达性。
- 沉浸科学与水剧场（3层或屋顶层）：数字穹顶或环幕剧场，净高10–14m，预留声学与消防分区，座席区荷载与振动控制满足设备规范。
- 修复工作坊与标本库（后场1–2层间或地下1层）：对公众半开放的标本修复与制作坊，玻璃隔断展示流程；库房区恒温恒湿，环境控制A/V级；气密门与缓冲间。
- 临展与联合创新实验场（2层）：模块化展台、可拆展基座、灵活照明与电力回路，支持跨学科临展、装置与工作坊。
- 环境要求：通用展线200–300lx；标本/化石与纸质材料≤50–150lx并控制UV；互动装置区500–800lx。中庭与主要展线背景噪声≤40 dB(A)；互动展区≤45 dB(A)；沉浸剧场观众席NC-20~NC-25。空调：展厅夏季22–26℃、冬季18–22℃，湿度45–55%RH（藏品敏感区）。消防与安全：按展品风险分级配置细水雾/气体消防，重载展基座设置防倾覆与抗震支座，展品与围护结构留设防震缝。

### 影院与表演区
影院类型与配置：
- IMAX球幕影院：200–250座，23米倾斜式球幕（投影FOV≥160°），8K分辨率双机激光投影，适合天体物理与海洋探索主题。
- 4D动感影院：70座（14排×5座），12米宽金属银幕，三自由度运动平台，环境特效（喷水/喷雾/风效），极地与气象主题。
- IMAX激光巨幕影院：250座（20排×12.5座/排），30米×21米激光校准银幕，12.1声道三维音效系统，适合恐龙灭绝与气候变化主题。

空间工艺：
- 净高：球幕厅净高≥25m（跨两层）；巨幕厅净高≥12m；4D厅净高≥8m。
- 结构：球幕厅30m×30m无柱空间（钢桁架+张拉索穹顶）；巨幕厅24m×32m大跨度（钢骨混凝土框架）；4D厅18m×24m（型钢混凝土梁柱）。
- 声学与隔振：球幕厅双层墙体+浮动地面（STC≥65，NC-20）；巨幕厅STC≥60；4D厅STC≥55。与安静展区间隔5m消防疏散通道，设备机房采用主动消音系统。
- 运营：影院区设置独立滨水侧门连通观景廊，夜间可单独开放；设置高速客梯（1.6m/s）与无障碍坡道。支撑房间布置于负一层：球幕投影机房约15m²、巨幕功放室约8m²、4D维保工作间约10m²；门厅配置约30m²3D眼镜消毒回收站、约15m²儿童安全座椅租赁处、约60m²可兼作夜间观景咖啡的等候区。

### 教育与活动区
教育理念从“参观”走向“探究”，把教育“嵌入”滨水生活的每一处场景，让公众在行动中理解科学。代表性活动与空间：
- 水岸好奇讲坛：200–300座报告厅，可升降舞台、投影与灯光，后台通道直达独立教育区；支持同传与无障碍座位。
- 水与光的实验秀：挑高中庭或大台阶前区，设护栏与软垫，可移动演示台与折叠观众阶梯；后台设安全净区与收纳。
- 星河过夜营：夜间独立出入口与值守室，通用教室分组切换；天台移动观测平台与望远镜位；地下或半地下多功能实验舱；与滨水步道安全连通。
- 智造工坊：开放工坊靠近展具储藏室，配备排风除屑、展示型收纳墙、可移动隔断；与展教资源共享通道。
- “酷玩列车”展厅巡回：展厅环线宽阔节点设停靠点、插座与固定锚点，临时“路演台”避开主要人流。
- 科学电影节：多功能影视厅（80–150座），高品质音响与投影，后台与展映资源库相连。

嵌入式实验室与公开表演：
- 在核心展厅与滨水主题展旁边布置“玻璃盒子”实验室/工坊：生命科学/水生态微型实验舱（微生物与水质检测、湿地沙盘）、物理/光学演示舱（可调光栅与波纹水槽，悬置演示台）、数据科学可视化舱（实时传感与数据大屏）；采用大玻璃+可开启通风与围挡，可视化与操作台分离。
- 首层门厅或中庭结合大台阶构成科学舞台：固定可折叠看台、护栏与软垫；设置可移动演示台、舞台灯光与音频，必要时临时遮蔽装置控制噪声；后台直达独立教育区的补给通道；展具储藏室就近配置。

独立教育区（建议配置）：2间通用多媒体教室（24–30座）、1间机器人工作室、1间湿法化学实验室、1间生命科学实验室、1间物理实验室、1间创客工坊、1间数字影像与科普剧排练厅、1间博物馆之友与课程资源库、1间接待/值守/安保与独立卫生间。分区策略：独立对外出入口与滨水步道短通；按噪声/气味分区与设备机房就近；夜间与周末开放预留独立照明、空调与安防通道。

### 公共服务区
入口门厅采用单向、无回流、入出分离流程。广场前设遮阳预排队区；售票与预约核验（自助+人工窗口）分流团队与个人；安检通道（多通道+X光机+手持安检）与存包区（智能储物柜+人工寄存）；末端检票闸机（标准+无障碍通道）。门厅净高不低于12m，必要时15–18m，形成立体采光与视觉焦点；人均占有面积按峰值客流3.5–4.0 m²/人配置，安检—检票段不低于2.0 m²。配套咨询台、导览屏、电子导览地图、团体/VIP通道与无障碍设施。

人性化与无障碍：
- 卫生间男女分设并设第三卫生间（无障碍），厕位比例建议1:2，至少每间卫生间配置1处无障碍；防滑地面、耐菌材料、自然采光与新风；无障碍坡道坡度不大于1:20、宽≥1.8m，设平台与扶手；盲道与防滑提示带，设置低位信息台与盲文标识。
- 母婴室按日接待1000人次配置不少于2间，单间≥12 m²；医务室（急救箱、AED、呼叫系统）与监护人休息带。
- 商业配套：餐饮/咖啡优先顶层或滨水景观面，独立的通风与厨房系统、开放视野落地窗与半室外露台；文创商店布置于出口必经路径，环形或折线布局提高转化率，设置展示台、互动试用区与双面收银；非经营性休息区散布于主中庭周边与展廊节点，采用可移动家具与小型视听区。

### 业务与后勤区
藏品管理与流线：采用“单向+递进”工艺流线，洁污分流。卸货平台（檐下与遮雨，回转场，净宽≥3.0m）→地磅与签收→缓冲间（脱尘/除湿、快速更衣与手消）→拆箱操作间→鉴选室→摄影室/影像室（6×9m拍摄台、轨道灯、减振、独立空调、遮光）→预登记与条码室（UPS+打印、条码/RFID）→入库缓冲间→藏品库。沿途设气闸与压差控制；危险品/特殊材料设独立通道与封闭收集点。库前区安全等级≥II级，双因素认证门禁（生物/卡片），闭路视频与行为分析；藏品出库须两人签核；电子围栏与防尾随系统覆盖。库前区与藏品库设封闭搬运通道与专用货梯，远离公众展线。

研究与修复：修复室/实验室分区布置，动静与洁污分区控制。摄影与分析检测优先北向稳定光或可控人造光；清洗、标本制作与化学实验室设通风与独立排风，形成负压梯度；危化品室与有机溶剂室设双重排风与互锁。恒温恒湿区温度20–22±2℃、湿度45–55±5%RH用于纸质与纺织类保护；地面与墙面抗渗、易清洁、可更换。振动敏感区楼板单位荷载≥1.5 kN/m²（常规修复间≥3.5 kN/m²），背景噪声≤35 dB（NC30）；设悬臂臂轨与减振台。防火分区与排烟/喷淋独立，可燃/有毒气体泄漏报警与联动。

行政与办公：行政办公与专业研究分区相对独立，设“大空间+独立办公室”组合，支持跨部门协作与灵活工位；人员与藏品流线独立，访客接待前置，不进入库前区与修复区。

整体流线组织：藏品流线、员工流线与观众流线“三线并行、各自闭环”。藏品通过专用门厅—封闭走廊—专用电梯—封闭候梯区；员工通过员工主入口—门禁—专用梯与走廊；观众通过公众门厅与展线，不进入藏品与修复区。安全策略为多因子门禁、视频监控、巡更与事件可追溯；紧急疏散楼梯独立于公众展线，室外设封闭等候区。
